# VIMS Opportunity Board update — 2026-10-12

This update is designed to be copied over the existing VIMS-hosted staging/production app without replacing the SQLite database.

## Changes

- Sets `page_navbar(fillable = FALSE)` so page height follows the opportunity list and the footer stays below the content.
- Forces the footer into normal document flow and gives it the VIMS navy/gold treatment.
- Updates the interface to the current VIMS palette:
  - `#06263b` navy
  - `#00677e` teal
  - `#85b8c7` light blue
  - `#ffffff` white
  - `#846838` gold
  - secondary greens/neutral as needed.
- Adds `owner_id` and `owner_email` columns to SQLite in a migration-safe way. Existing records remain unchanged; these fields are `NULL` until future SSO integration.
- Extends `submit_opportunity()` so a future SSO submission can provide an authenticated owner and optionally publish immediately without changing the public form today.
- Adds `fetch_owned_opportunities(owner_id)` as a small future-facing helper for a contributor management page.
- Adds `scripts/show_schema.R` for a quick database-schema check.

## Existing database

Do **not** replace `/var/lib/vims-opportunity-board/opportunities.sqlite`. Running `scripts/initialize_database.R` after deploying this update adds the two new nullable ownership columns automatically.
